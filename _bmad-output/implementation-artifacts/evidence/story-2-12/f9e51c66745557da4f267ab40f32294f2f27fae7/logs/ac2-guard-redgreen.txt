########## assertion 5 — "only root-declared submodules are initialized" ##########
Fix under test: INITIALIZED must filter on the leading '-' that `git submodule status` uses to mark
an uninitialized submodule. Without the filter the comparison is a tautology that can never fail.

declared set: references/Hexalith.Builds, references/Hexalith.EventStore

  input                             old (awk '{print $2}')   new (awk '$1 !~ /^-/ {print $2}')
  --------------------------------  -----------------------  ---------------------------------
  all initialized                   PASS                     PASS
  one uninitialized ("-cccc ...")   PASS  <-- the defect      FAIL  <-- correct

The old filter reports the declared and initialized sets as equal even when a submodule is NOT
initialized, which is precisely the condition assertion 5 exists to reject.
