# Retained development trials

These are nonfinal, unqualified execution receipts, retained including every
failed case. They are never imported into the final source-bound packet.
The initial trial exposed invalid snapshot interval, source registration,
multiple fixture streams, and the shared inotify watch limit. Corrected smokes
proved persisted protected effects and recovery; the scheduler needed its
actual loopback broadcast port. A smoke cleanup detected two independently
created containers while preserving the original four shared containers.
The second full invocation was deliberately interrupted to add feasible
historical 3.110.0 capability endpoints; it retained its interrupted case and
completed owned cleanup. The final invocation has a separate frozen source
closure and fresh receipts. No trial grants qualification or owner acceptance.
Database dumps, generated credentials, and invocation scratch were destroyed.
