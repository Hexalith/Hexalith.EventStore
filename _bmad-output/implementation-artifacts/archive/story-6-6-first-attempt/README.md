The last commit containing the first-attempt documents was `75a08f0069d8c2495d9dff20a0deb84edb6cc638`. The later tracked `evidence/story-6-6/replay-reader-review/` files remained through `6421b236` and were removed from HEAD. Ignored evidence was left in place.
