# EventStore architecture rubric review

Reviewed the complete Phase 4 architecture spine on November 21, 2026. Its SHA-256 is `7ad8fe0af4e9eb42903b3a2d08577b07eef21112f2a9f8a8a64fd01c15a921f6`. The source checkout is EventStore `df5dc226a`. The BMad spine linter returned zero findings.

A source-selection requirement also conflicts with the current build. The existing Phase 4 readiness rejection remains in force. | High | **The AD-28 channel-token rule skips Development.** Line 380 requires validation on non-Development Dapr endpoints. The shared verifier requires a configured token and accepts only a valid result in every environment. A team following AD-28 could omit the check on a channel-protected Development route and still claim conformance. This concerns request admission. Require the receiving application's channel token on every channel-protected route in every environment. Keep public probes, startup behavior, and additional workload or delegated-user checks distinct.
