V-C2

Critical Tenant identity has no canonical source or normalized form; the tree already holds three incompatible readings

Raised by Adversarial C1 · Security H2 · Rubric M7
Spine
The State-keys row :468 says where tenant identity appears, never where it comes from, who validates it, or its canonical string form. AD-10 :151, AD-25 :406, AD-7 :133, and AD-8 :139 all depend on the answer.
Tree
  • Contracts/Identity/AggregateIdentity.cs:28-29 lowercases tenant and domain; every actor ID and state key is built from that form.
  • ClaimsTenantValidator.cs:44-45 and AdminTenantAuthorizationFilter.cs:46-49 compare Ordinal against eventstore:tenant.
  • Admin.Server/Services/DaprProjectionQueryService.cs:77-79,205-206 compares OrdinalIgnoreCase and adds a TenantAllSentinel.
  • SignalR groups use the raw string (ProjectionChangedHub.cs:79-82): a client in Proj:Acme never receives a broadcast keyed Proj:acme.
  • Admin.Server defaults an omitted tenant to the caller's first grant (AdminBackupsController.cs:538-547, AdminConsistencyController.cs:148-182); the gateway rejects. MCP defaults to session context. Admin.UI mints its own JWT with a tenants array from configuration.
  • Generated REST RestTenantSource.System emits the literal "system", unnormalized.
Divergence
Story 7.2 (ordinal canonical claims) vs the Story 4.7 / 1.9 lineage (lowercase read-model addresses). A principal with claim Acme is authorized for Acme, stores under acme, subscribes to group Acme, and admission partitions on whichever string the adapter passes. Under NFR2, "omit the tenant, receive the first grant" is compliant with the text as written.
autofixOne Convention row, Tenant identity: explicit in the request and never defaulted from grants, session, or configuration; authorized once at the first application boundary via the single claim type eventstore:tenant; canonical form is the AggregateIdentity form produced by one platform normalizer in Contracts; every downstream hop carries the validated value and never re-derives it; system is reserved. Plus an AD-10 clause that authorization compares canonical identity only.
